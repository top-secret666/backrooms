# Backrooms

First-person horror set in Level 0 of the Backrooms: endless procedurally generated yellow rooms, buzzing lights, and something that hears you.

Goal: find the exit in 10–15 minutes.

## Tech

- Unity 6 LTS, URP, New Input System
- Game logic (generation, pathfinding, state machines) in pure C#, covered by EditMode tests
- Dependency injection via VContainer, events instead of singletons
