# 12.10 — Kane Pixels corridor (6 часов Unity)

Билеты сегодня **не делаем**. Цель: узкий T-коридор Level 0 + люминесцентные лампы.

## Референс (Kane Pixels)

- Узкие коридоры (~3–4 м), не огромный зал
- Потолок низкий (~3–3.2 м)
- Жёлтые обои + мокрый ковёр + плиточный потолок
- Сетка люминесцентных панелей, лёгкое мерцание
- Тускло, влажно, «офис без окон»

## Час 1–1.5 — собрать каркас

1. Открой `Level0_Greybox`.
2. Меню **Backrooms → Build Kane-Style T-Corridor**.
3. В Hierarchy появится `Level0_Corridor`.
4. Старые `Plane` / `Cube*` / `Ceiling` / одиночный `Point Light` — **выключи** (галочка Active) или удали, чтобы не пересекались.
5. `Player` → Position `(0, 1, 0)`.
6. Play → пройди главный коридор и сверни в северный отрог.

## Час 1.5–3 — свет и атмосфера

1. Выдели любую лампу под `Level0_Corridor/Lights/.../Point Light`.
2. Смотри `Light`: Color тёплый жёлтый, Range ~8, Intensity задаёт `FlickeringLight`.
3. Подкрути на одной лампе `FlickeringLight` (Base/Min), потом **скопируй компонент** на другие или правь префаб позже.
4. Directional Light должен быть выключен (билдер пытается отключить).

## Час 3–4.5 — материалы под Kane

1. `Mat_Carpet_Office` — Base Color тёплый грязно-жёлтый/оливковый, Tiling ~10–12.
2. `Mat_Wallpaper_Office` — не пересвечивать; Tiling по высоте стены.
3. `Mat_Ceiling_Office` — грязно-белый, Tiling 4–6.
4. Сравни с кадром из Kane Pixels (пауза на коридоре).

## Час 4.5–6 — расширить руками (учёба)

Без билдера, **руками** добавь одно из:

- короткий L-поворот в конце spur, **или**
- тупик с колонной, **или**
- второй ряд ламп / одну «мёртвую» лампу (Intensity ≈ 0)

Разбери вслух: почему стены — Cube, пол — Plane, лампа — Cube + Point Light + `FlickeringLight`.

## Готово, когда

- [ ] Ходишь по T-коридору без дыр в полу
- [ ] Несколько мерцающих ламп на потолке
- [ ] Старая квадратная комната не мешает
- [ ] Можешь объяснить структуру `Level0_Corridor` в Hierarchy

## Завтра (коротко)

Билет **или** ещё кусок лабиринта — через раз. Приоритет: Unity.
