# Kane Pixels corridor — чеклист

Разделение: **ты — Unity Editor**, **агент — скрипты**.

## Почему «всё пропадало»

1. **Не сохранялась сцена** — правь Hierarchy → сразу **Ctrl+S** (Save).
2. Меню **Backrooms → Build Kane-Style T-Corridor** раньше **удаляло** объект `Level0_Corridor`. Если куски HELL были внутри него — они тоже исчезали.
3. Если перетащить стену **под `Lights`**, она «теряется» в Hierarchy и уезжает по координатам.

Сейчас билдер **спрашивает** перед rebuild и **никогда не трогает** объекты `HELL`.

## Hell-крыло (правильно)

Твои стены назывались **`Wall_Hell_E` / `Wall_Hell_*` внутри `Level0_Corridor`** — не отдельный корень.

На диске/в git имён `Wall_Hell_*` **не было** (работа не сохранилась через Ctrl+S / сцена перезаписалась). Восстановить старые точные позиции нельзя.

### Как вернуть Hell сейчас
1. Дождись компиляции скриптов.
2. Меню **Backrooms → Add or Refresh Hell Wing (Wall_Hell_*)**
3. В Hierarchy под `Level0_Corridor` появятся: `Wall_Hell_N/S/E/W`, `Floor_Hell`, `Ceiling_Hell`, `Hell_Lights`
4. Сразу **Ctrl+S**
5. Play → иди на **запад** (к −X), в крыло Hell

Отдельный объект `HELL` в корне — путаница от дубликата; он выключен. Не используй его.

## Правила работы в Unity

1. После любого сдвига стены/пола → **Ctrl+S**
2. Новые куски клади **внутрь `HELL`**, не внутрь `Lights`
3. **Не жми Build**, пока правишь HELL (или жми Cancel в диалоге)
4. Дубликат: Ctrl+D → сразу переименуй в `HELL` / `HELL_Wing2`
5. Если Unity спросит «Reload» сцену с диска — смотри, нет ли несохранённых правок в Editor
